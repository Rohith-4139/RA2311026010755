# AffordMed Notification System

## 📌 Features
- Fetch notifications using API
- Bearer token authentication
- Priority sorting:
  - Placement (High)
  - Event (Medium)
  - Result (Low)
- Displays top 10 notifications

## 🛠 Tech Stack
- Node.js
- Axios

## ▶️ How to Run
1. Install dependencies:
   npm install

2. Add token in code

3. Run:
   node index.js

## 📁 Project Structure
- notification_app_be → Backend
- logging_middleware → Logging API
- notification_app_fe → Frontend

## 📊 Output
Displays top notifications sorted by priority and timestamp.
